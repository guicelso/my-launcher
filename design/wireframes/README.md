# Wireframes (protótipo de alta fidelidade)

Fontes do canvas publicado em https://claude.ai/artifact/SiHfRy4w698zHFTzvYiXv6

- `canvas.json` — índice do canvas (posição e título de cada artboard)
- `*.dc.html` — uma tela por arquivo (formato Design Component: HTML + bloco `<script type="text/x-dc">`)
  - `Main` (painel; props `theme` = noite|dia, `mapa` = proprio|embutido), `HomeDay`, `HomeEmbedded`
  - `MapFull`, `Media`, `AppDrawer`, `Settings`
  - `Rail` (barra lateral, importada pelas demais)

Os arquivos são a referência visual das specs 002–008. Ao mudar o design, atualize aqui e no canvas.
